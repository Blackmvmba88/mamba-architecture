## Utilidades

### Script Auto-Mark Viewed para GitHub PRs

Este repositorio incluye un script útil para marcar automáticamente todos los archivos de un Pull Request como "Viewed" en GitHub.

**Uso:**
1. Abre un Pull Request en GitHub en tu navegador
2. Abre la consola del navegador (F12 o clic derecho → Inspeccionar → Consola)
3. Copia y pega el contenido de `scripts/auto-mark-viewed.js`
4. Presiona Enter para ejecutar

El script marcará automáticamente todos los archivos no vistos como "Viewed" y mostrará un mensaje con el conteo de archivos procesados.
